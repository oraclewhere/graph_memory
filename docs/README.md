## 三分钟看懂这个项目

**它是什么**：一个英文单词记忆图服务。核心是 `autoMake` 自生长循环：

```
种子单词 → LLM 生成例句 → 例句中的新单词入图 → 新单词再作为种子 → ...
```

如此反复，长出两张互相促进的图——**例句图**（单词 ↔ 例句 ↔ 分类）和
**单词图**（单词之间通过共享英文前缀/后缀关联）。

**两个核心概念**：

- **权重**（度中心性）——基于六度空间理论，一个单词关联的节点越多越核心，记忆收益越高。实时计算，不落库。
- **收敛强度**（`intensity ∈ [0,1]`）——在权重光谱上的采样锚点。
  **高 = 收敛**（取核心词，图变密），**低 = 扩张**（取边缘生词，图长大）。

**闭环为什么不需要人工回灌**：新入图的词度数天然最低，低强度下会被自动选成下一轮种子。
